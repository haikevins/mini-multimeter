# Mini Multimeter v1.0.0

`v1.0.0` is the first formal stable release of Mini Multimeter. It packages the existing validated STM32F103C8T6 firmware without changing the firmware source used for the release-preparation work.

## Highlights

- Resistance measurement using an ADC voltage-divider path with filtering and explicit open-socket handling.
- Capacitance measurement using a non-blocking RC charge/discharge state machine.
- PWM frequency and duty-cycle capture with timer ranges selected for the expected input frequency.
- Programmable PWM generation from 1 Hz to 100 kHz.
- LCD1602 user interface driven by explicit state machines rather than blocking application delays.
- Internal-Flash configuration storage protected by version checks, CRC-32, range validation, and programming read-back.
- USART1 diagnostics and centralized in-RAM error tracking.
- Layered firmware structure separating application policy, services, hardware drivers, diagnostics, and platform support.

## Reproducing the release images on Ubuntu

Requirements:

- Python 3
- `arm-none-eabi-objcopy` (preferred) or GNU `objcopy`
- a successfully linked `MDK/Objects/mini-multimeter.axf`

Run:

```bash
python3 scripts/release/package_firmware.py \
  --axf MDK/Objects/mini-multimeter.axf \
  --version 1.0.0 \
  --output-dir ~/Downloads/mini-multimeter-v1.0.0
```

Then verify:

```bash
cd ~/Downloads/mini-multimeter-v1.0.0
sha256sum -c SHA256SUMS
```

The packaging script reads the linked AXF, extracts only loadable segments whose physical addresses are in STM32 Flash, fills internal Flash gaps with `0xFF`, writes the raw BIN, converts that BIN to Intel HEX, and generates `SHA256SUMS`. It does not modify the firmware source tree.
